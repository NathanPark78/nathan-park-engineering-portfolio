# Approved portfolio media

Create one folder per project slug, for example:

```text
assets/media/niddk-wearable/
assets/media/astro-flexion/
assets/media/lilly-validation/
assets/media/phoenix-research/
assets/media/pulseox-enclosure/
```

Add only publication-safe, permission-cleared media. Recommended web formats:

- `.webp` or compressed `.jpg` for photographs
- `.png` for diagrams requiring crisp text
- `.mp4` and `.webm` for short muted demonstrations
- a poster image for every video

Record the source, permission status, and supported claim outside this public directory before publishing.
